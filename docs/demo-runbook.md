# Demonstration audit archive

This address retains an early repository-readiness audit. The complete findings and then-open
items are in the [fixed source revision](https://github.com/twinkling-reality/exulanica/blob/857cffe730dad97f9edb34535c773115277e2769/docs/demo-runbook.md).
Its missing-API and missing-application statements describe that audit, not the runnable system.

For demonstration preparation, use [demonstration integrity](demo-integrity.md),
[development setup](development-setup.md), [deployment](deployment.md) and the
[product acceptance gates](product-direction.md#delivery-gates-for-the-first-demonstration).
Validate the selected journey against its actual services and source rights. A retained recording
or successful fixture does not prove the live path.

Immutable records name this path, so it remains available. The original audit does not supply an
active task list, a deployment guarantee or permission to run an external service.
