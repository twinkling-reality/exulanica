# Documentation standard

Identify a thing by what it is, not by when you looked at it.

That rule covers dates, versions, phases, and status words. It is not a ban on
dates. The same rule covers markdown, comments, docstrings, and help text. It
does not rewrite executable behaviour.

## Readers

A document serves an arriving developer and an agent using it as context. Both
fail the same way: prose that was true when it was written and is not true of
the tree the document sits in.

## Event or state

A date attached to an event stays. A date standing in for "this is how things
are" goes. What replaces a state date is the thing's identity: a digest, a
record id, a file path, a contract version, a named rule.

| Stays | Goes |
| --- | --- |
| A measurement with when, on what, and the figure | "as of 2026-09-15 the carve reads low parts" |
| A decision date in an ADR or decision log | "Updated 2026-09-17" as a freshness stamp |
| A dated retraction or correction | A version number used to date a statement |

The version case is easy to miss. "Since tessellator 14 the carve reads low
parts" is true, useful, and breaks when the number moves, because the version
is a moving field and the prose is not. Write present tense about the tree the
document sits in.

In code, a word that names the moment of execution stays: work that is eligible,
a lock another process holds, terms that are valid at call time. A word that
names the moment of writing goes: "for now this skips validation", "the new API".

## Words that expire

Do not use these of the system, or of a comment that describes the system:

| Class | Words |
| --- | --- |
| Present-as-written | currently, at present, as of now, for now, at the moment, today |
| Forecast | recently, soon, shortly, next, coming, planned, we will, is being |
| Time labels | phase 2, milestone 3, stage 4 used as a clock rather than as the name of a thing that exists |
| Silent inversion | new, old, legacy, the new X |
| Status that expires | experimental, in progress, not yet, temporary, TODO in prose |

A tracked ticket is a name. A sentence that describes the world is not.

`today` used of calendar time in a measurement stays. `today` used of the
product goes.

## Form

| Rule | Meaning |
| --- | --- |
| One document, one subject | The first line names it |
| Present tense, active voice | No first-person plural |
| Claims about code | Link to the code, or state how the claim was measured |
| Generated artefacts | Name the generator and the command |
| Headings | Nouns, not sentences |
| Punctuation | No em dash. Use a comma, a colon, or a full stop |
| Parallel facts | A table, not a list of similar sentences |
| Negatives | State what a thing does not do where a reader would assume otherwise |

Do not change what a document or comment claims. If a sentence looks wrong,
report it. Rewriting an unverified claim is how a documentation pass introduces
a bug that outlives it.

Do not rename an identifier to satisfy this standard. A constant that names a
withdrawn path is a name, not a status adjective.

A test that asserts an exact string is a contract. Change the comment beside it,
not the asserted text, unless that text is itself authorial prose.

## Hard rules

| Rule | Why |
| --- | --- |
| `docs/evaluation/` is append-only | Records bind digests of each other. Editing one breaks the provenance chain. Do not reformat, fix typos, or standardise a file in it. Report an error; do not touch it |
| Do not hand-edit a generated file | A test asserts the file matches its generator. Change the generator and re-run it |
| Do not write the withdrawn pre-release product name | A suite-wide scan fails on a new occurrence outside a reviewed allowlist. Name things without that word and without paths that contain it |
| `git check-ignore -v` before assuming a path commits | Several documents under `docs/` are gitignored |
| Do not read private operator trees | Public records carry a hash of private words, not the words |

## Filing

| Directory | Contents | Later edits |
| --- | --- | --- |
| `docs/` root | Living contracts and reference | Yes |
| `docs/capabilities/` | Guides for people choosing to use the product | Yes |
| `docs/adr/` | Numbered decisions with alternatives | Status may change; the number never does |
| `docs/evaluation/` | Digest-bound evidence | Never |

A file named for a phase or a calendar day expires by name. Name it for the
subject.

The catalog `docs/all-documents.md` is generated by
`uv run python scripts/generate_docs_index.py`. Do not edit it by hand.
