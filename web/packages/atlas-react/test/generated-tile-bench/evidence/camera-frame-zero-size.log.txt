Report from the merge review: the first time the Browser pane opened ?preview=1&tile=tile-conformance, the page logged
three PlayCanvas asserts, FRAMEBUFFER_INCOMPLETE_ATTACHMENT for PrepassRT, SceneColor MSAA and WebglFramebuffer MSAA.

Method: headless Chrome 152 at 1440x900 against the app dev server (tile-runtime-web, 5192). A script added before any page
script (camera-frame-zero-size-plan.json.txt, run by cdp-capture-zero-size.mjs.txt) holds every canvas at 0 by 0 CSS pixels
until the tile statement is on screen, then releases it. It wraps console to record each FRAMEBUFFER assert with its time,
the canvas size and whether the zero style was still in force. `framePasses` is the atlas-camera's camera frame pass count.
Before each run the served module was checked with curl until it contained (or lacked) `createFrame`: Vite took up to 17 s
to serve an edit, and one earlier run measured a stale module.
